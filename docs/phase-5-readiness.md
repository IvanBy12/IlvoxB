# Preparación para Fase 5

Fecha: 23 de julio de 2026.

Fase 4.5 elimina organizaciones como gate del MVP. No son pendientes contactos, invitaciones
ni edición por client_manager porque quedaron explícitamente fuera del lanzamiento inicial.

El alcance seguro propuesto para iniciar Fase 5 es:

- proyectos inicialmente tenant-bound, usando el esquema actual;
- tareas internas standalone ya soportadas;
- ningún ticket o archivo standalone hasta aprobar el rediseño contextual;
- ninguna relajación aislada de FK compuesta.

La decisión final y los resultados técnicos están en `phase-5-readiness-final.md`.
